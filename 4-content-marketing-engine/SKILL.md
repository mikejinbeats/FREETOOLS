# Content Marketing Engine

Transforms empty websites into persuasive, SEO-optimized content machines that convert visitors and rank on Google.

## Core Mission

When a user says **"Preciso de conteúdo para o site"**, this skill:
1. **Analyzes context** (niche, audience, goal, tone)
2. **Selects frameworks** (AIDA, PAS, Storytelling, etc.)
3. **Generates copy** tailored to specifications
4. **Optimizes for SEO** (keywords, structure, meta)
5. **Delivers ready-to-paste** content with formatting

**Complete customization** - the skill adapts 100% to user's prompt instructions.

## Marketing Frameworks Library

The skill can implement any framework based on user request:

### Framework 1: AIDA (Attention, Interest, Desire, Action)
**Structure:**
- **Attention:** Bold headline that stops scroll
- **Interest:** Hook with relatable problem or surprising fact
- **Desire:** Paint the transformation, show benefits
- **Action:** Clear CTA with urgency

**Best for:** Traditional sales pages, email marketing

### Framework 2: PAS (Problem, Agitate, Solution)
**Structure:**
- **Problem:** Identify the pain point clearly
- **Agitate:** Make them feel the pain deeply
- **Solution:** Present your offer as the cure

**Best for:** B2B services, high-ticket products

### Framework 3: Hero's Journey (StoryBrand)
**Structure:**
- Customer is the hero
- They have a problem
- You are the guide (not the hero)
- You give them a plan
- Call them to action
- Show what success looks like
- Show what failure looks like (stakes)

**Best for:** Service businesses, coaching, consulting

### Framework 4: Feature-Advantage-Benefit (FAB)
**Structure:**
- **Feature:** What it is/does
- **Advantage:** How it's different
- **Benefit:** What it means for the customer

**Best for:** SaaS products, technical products

### Framework 5: Before-After-Bridge (BAB)
**Structure:**
- **Before:** Describe current pain state
- **After:** Paint the ideal future state
- **Bridge:** Show how your product gets them there

**Best for:** Transformation products (courses, fitness, self-help)

## Tone of Voice Library

The skill adapts writing style based on prompt:

### Tone 1: Casual/Friendly (Startup, Young Brand)
- Short sentences
- Contractions (we're, you'll, it's)
- Conversational language
- Emojis acceptable
- "You" language (direct address)

**Example:**
> "Here's the thing: Excel doesn't have to suck. We get it — spreadsheets feel like a chore. But what if you could actually *enjoy* making dashboards? (Wild, we know.) Let's make it happen."

### Tone 2: Professional/Corporate (B2B, Enterprise)
- Longer, structured sentences
- Formal language, no contractions
- Data-driven, focus on ROI
- Third-person acceptable
- Industry terminology

**Example:**
> "Organizations implementing our Excel training platform report an average productivity increase of 34% within the first quarter. The comprehensive curriculum addresses advanced functions, automation, and business intelligence integration."

### Tone 3: Luxury/Premium (High-End Services)
- Sophisticated vocabulary
- Aspirational language
- Sensory descriptions
- Exclusivity framing
- Quality over price focus

**Example:**
> "Discover a sanctuary where dental excellence meets uncompromising luxury. Our artisan approach to oral health combines Swiss precision with Portuguese warmth, curated exclusively for discerning clients who value their wellbeing."

### Tone 4: Technical/Educational (Tech Products, Courses)
- Clear explanations
- Terminology defined
- Step-by-step logic
- "How it works" focus
- Credibility through expertise

**Example:**
> "Our algorithm leverages machine learning to analyze over 50 data points per lead, assigning predictive scores based on historical conversion patterns. This enables sales teams to prioritize high-intent prospects with 87% accuracy."

### Tone 5: Inspirational/Motivational (Coaching, Personal Development)
- Empowering language
- Emotional resonance
- Future-focused
- Transformation narrative
- "You can" messaging

**Example:**
> "You're not broken. You're not behind. You're exactly where you need to be to take the next step. And that step? It starts with believing that your dreams aren't just possible — they're inevitable."

## Execution Workflow

### Phase 1: Context Analysis

**Extract from user prompt:**
1. **Niche/Industry:** What business/product? (e.g., "SaaS de automação", "clínica dentária")
2. **Target Audience:** Who are they? (e.g., "empresários 35-50", "mães jovens")
3. **Goal:** What action? (e.g., "comprar agora", "agendar demo", "baixar ebook")
4. **Tone:** How to speak? (e.g., "casual", "profissional", "luxo")
5. **Framework:** Which structure? (e.g., "AIDA", "PAS", "storytelling")
6. **Length:** How much? (e.g., "hero section só", "página completa", "5 artigos")

**If information missing, use smart defaults:**
- Tone: Professional (safe default)
- Framework: AIDA (most versatile)
- Length: Full page copy

### Phase 2: Keyword Research (for SEO Content)

For blog articles or SEO pages, identify:
- **Primary Keyword:** Main search term (e.g., "dentista Barreiro")
- **Secondary Keywords:** Related terms (e.g., "clínica dentária Barreiro", "tratamentos dentários")
- **Long-tail Keywords:** Specific phrases (e.g., "melhor dentista Barreiro preços")

**Keyword Integration Rules:**
- Primary keyword in H1 (title)
- Primary keyword in first 100 words
- Secondary keywords in H2s (subheadings)
- Natural density: 1-2% (avoid keyword stuffing)
- Use synonyms and related terms

### Phase 4: SEO Optimization Pass

For all web content (not emails), ensure:

**On-Page SEO Checklist:**
- [ ] Primary keyword in H1
- [ ] Primary keyword in first 100 words
- [ ] Secondary keywords in H2s
- [ ] Alt text for images (if applicable)
- [ ] Internal links to 2-3 related pages
- [ ] External links to 1-2 authoritative sources
- [ ] Meta description 140-160 characters
- [ ] URL slug contains primary keyword
- [ ] Content length 1000+ words for blog posts
- [ ] Readability: Short paragraphs (2-4 sentences)
- [ ] Scannability: Subheadings every 200-300 words

**Content Structure:**
- Use "inverted pyramid" (most important info first)
- Answer the main question in the first paragraph
- Use bullet points and numbered lists
- Include a table of contents for long articles
- End with a clear CTA

## Output Validation Checklist

Before delivering content, verify:

**Copy Quality:**
- [ ] Headline grabs attention (passes "so what?" test)
- [ ] Value proposition clear in first 5 seconds
- [ ] Benefits > Features (translated to customer language)
- [ ] CTA is specific and action-oriented
- [ ] No jargon unless target audience expects it
- [ ] Tone matches brief consistently

**SEO Quality (for web content):**
- [ ] Primary keyword present but natural
- [ ] Meta description compelling + keyword
- [ ] H1, H2 structure logical
- [ ] Content length appropriate (1000+ for blog)
- [ ] Internal linking suggestions provided

**Persuasion Elements:**
- [ ] Social proof included (if applicable)
- [ ] Urgency/scarcity (if appropriate for goal)
- [ ] Risk reversal (guarantee, trial, etc.)
- [ ] Objection handling (FAQ or inline)

**Readability:**
- [ ] Flesch Reading Ease: 60+ (conversational)
- [ ] Sentence length: Average 15-20 words
- [ ] Paragraph length: 2-4 sentences max
- [ ] Subheadings every 200-300 words
